# VAN—BREAST — frontend local

Prototipo construido solamente con HTML, CSS y JavaScript. No requiere Node,
React, paquetes, instalación ni conexión a internet.

## Opción rápida

Abre `index.html` con doble clic.

## Opción recomendada

Desde esta carpeta ejecuta:

```powershell
python -m http.server 8000
```

Después visita:

```text
http://localhost:8000
```

El formulario de acceso ya contiene datos de demostración. Los cambios realizados
en participantes viven solamente en memoria y se pierden al recargar la página.
Esto permitirá integrar Flask y una base de datos más adelante sin tener que
reemplazar el diseño.
